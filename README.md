# John Gabriel Mmbando — Portfolio

A responsive, static portfolio site built with HTML, CSS, and JavaScript. It has no build step or paid service requirement.

## Publish on GitHub Pages

This portfolio is prepared in the public `Johngabri/john-mmbando-portfolio` repository. To publish it, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

The expected website address is `https://johngabri.github.io/john-mmbando-portfolio/`. GitHub will show the final public address on the Pages settings screen after the first deployment completes.

GitHub Pages is free for public repositories on GitHub Free. Publishing makes the repository files and profile content publicly viewable.

## Update the profile

Edit `index.html` in the repository to change the site text. Confirm job titles, employers, dates, responsibilities, achievements, and course status against an approved CV or supporting records before adding them. The quantified figures from the initial brief are not displayed until verified.

Before publishing or when details are ready, you can also:

- Replace the portrait placeholder with an approved professional photograph.
- Add earlier roles and exact employment dates from the current CV.
- Add a LinkedIn URL after confirming the exact profile address.
- Add an approved CV PDF to the repository and link it from the documents section.
- Replace planned analytical samples after completing them with synthetic or public data.

## Contact behavior

Email buttons open the visitor's email application with a prefilled subject. The site does not collect or store contact form data. A server-side contact form would require a separate form service or backend.
