# John Gabriel Mmbando — Portfolio

A responsive, static portfolio site built with HTML, CSS, and JavaScript. It has no build step or paid service requirement. The profile photo is stored in `profile.jpg`.

## Publish on GitHub Pages

This portfolio is published from the public `Johngabri/john-mmbando-portfolio` repository. Its GitHub Pages source is the `main` branch and `/(root)` folder. The site root immediately redirects to `/portfolio/`, which is the main professional profile. The four interactive cases remain available as a section in the profile and on their independent `/case-studies/` page.

The website address is `https://johngabri.github.io/john-mmbando-portfolio/`.

GitHub Pages is free for public repositories on GitHub Free. Publishing makes the repository files and profile content publicly viewable.

## Update the profile

Edit `portfolio/index.html` to change the profile text. The root `index.html` only redirects to the profile. Replace `profile.jpg` to change the portrait. Confirm job titles, employers, dates, responsibilities, achievements, and course status against an approved CV or supporting records before changing them.

The public profile includes the verified role dates, current CPA study status, LinkedIn address, contact details, and selected achievements from the latest CV. The CV itself is available by request.

The portfolio includes an independent budget-performance review at `portfolio/budget-dashboard.html` with a downloadable PDF interpretation and a ZIP containing the category summary, monthly detail, supporting-record review, forecast scenarios, and data guide. All figures are synthetic and must remain clearly separated from verified employment achievements. Add new analytical samples only after completion, using synthetic or public data.

The four independent interactive case studies each provide a browser-generated PDF report. Each report includes its fictional case figures, the effect of every available choice, and the selections and simulated result visible when it is downloaded. Reports are generated locally in the visitor's browser and do not use a backend.

## Contact behavior

Email buttons open the visitor's email application with a prefilled subject. Phone and LinkedIn links open their respective contact destinations. The site does not collect or store contact form data. A server-side contact form would require a separate form service or backend.
